# 暗火三消

像素风暗黑三消 RPG。三消只增效，战斗是实时 RPG（力量 / 智力 / 敏捷）。

技术栈：**Phaser 3 + Vite + TypeScript**。

- 产品规格：[docs/product.md](docs/product.md)
- 路线图：[docs/roadmap.md](docs/roadmap.md)
- 试玩页：https://betgo.github.io/anhuo-sanxiao/

## 开发

```bash
npm install
npm run dev
```

## 构建（Pages 发 `dist/`）

```bash
npm run build
```

## 测试

```bash
npm test
```
