# Art pack v2（生图模型）

目标布局：上下分——战场在上、棋盘在下（用户选定第一张参考）。

## 目录
- `layout/` 战斗页整页参考
- `bg/` 战斗背景（不含角色或含占位）
- `board/` 棋盘底板与棋子风格
- `beads/` 四色珠：r/b/g/y
- `ui/` 面板、按钮、血条等
- `sheets/heroes/` 三职业精灵图集（idle×2, hurt, attack×3）
- `sheets/enemies/` 十敌+领主图集
- `frames/` 从图集拆出的单帧（后续）

## 约束
- 正式进游戏槽位前需再压成硬边像素（48×48 角色 / 32×32 珠）；本包为生图参考与替换候选。
- 精灵图集提示词见技能「精灵图集生图」。
